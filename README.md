# mouthoffmedia.com

Mouth Off Media — web design & digital solutions. A brand of WealthEdge Ventures Inc. dba Wisdom Digital.

- Edit `scripts/build.py` (contact details are the `CONTACT_*` constants at the top), then run `python3 scripts/build.py`.
- `public/` is the deployed site (GitHub Pages via Actions). Includes PWA manifest, service worker, sitemap, robots.txt, llms.txt.
